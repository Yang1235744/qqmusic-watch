功能一览

✅ 在线搜索

按歌名 / 歌手 / 专辑搜索，调用 QQ 音乐公开 Web API。

✅ 在线播放

m4a 格式流媒体播放，AVPlayer 硬件解码，续航友好。

✅ 播放队列

点击搜索结果整组入队，播完自动切下一首；支持上一曲 / 下一曲。

✅ 歌词显示

播放器页展开歌词面板，跟随进度高亮滚动当前行。

✅ 离线缓存 NEW

点击下载按钮将歌曲存至本地 CachedData/，无网络时优先播放本地版本。

✅ QQ 登录框架 NEW

OAuth 2.0 完整框架（扫码 / 密码 / Code 回调），token 持久化，开发者只需填入 AppID 即可接入。

✅ 云端收藏 NEW

登录后开启"云端同步"开关，本地收藏自动上传至 QQ 账号（需接入云接口）。

✅ 后台播放 NEW

声明了 backgroundModes: audioPlayback + MEDIA_CONSOLE 权限，App 切后台仍可继续播放。

✅ 深色 AMOLED

纯黑背景 + 粉色点缀，适配 1.82″ 矩形 OLED 屏幕，省电。

接入 QQ 登录（给后续开发者的说明）

// 1. 在 QQLoginManager.ets 中填入你的 QQ互联 AppID const QQ_CLIENT_ID = 'YOUR_APP_ID'; // https://open.qq.com 注册获取 const QQ_REDIRECT_URI = 'https://your-domain.com/callback'; // 2. 启动时调用初始化（EntryAbility.onCreate） await QQLoginManager.getInstance().init(); // 3. 登录入口（首页右上角头像 → UserSettingsPage） await QQLoginManager.getInstance().loginWithQRCode(); // 二维码扫码 await QQLoginManager.getInstance().loginWithCode(code); // 扫码后拿到 code 调用此方法 // 4. 退出登录 await QQLoginManager.getInstance().logout();

快速开始

  1. Fork 本仓库 点击 GitHub 右上角 Fork，获得你自己的副本。
  2. 申请开发者证书 登录 AGC 控制台，生成 CSR → 申请调试证书 → 下载 Profile（.p7b）和证书（.cer）。
  3. 放入 sign/ 目录 将 .p12、.cer、.p7b 复制到项目的 sign/ 文件夹，修改密码。
  4. 用 DevEco Studio 打开 & 构建 选择目标设备（Watch Fit 3 或模拟器），Build → Build Hap(s)，然后一键安装到手表。
